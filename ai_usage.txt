Перевірка результатів (виконано вручну студентом):
- --ast для робочого прикладу Task 1 з методички (i64 a, bool b/c/d/e,
  i32 x, i64 y/z, вираз y := y*z+a) звірено вручну з очікуваною формою
  дерева — збігається.
- Той самий приклад прогнано через lli: "Program exit with result 385"
  — збігається з очікуванням у PDF. exit e (bool, true) дає
  "Program exit with result true".
- Дві лексичні помилки з попередження Task 1: "a = 1" дає
  "line 2:3: expected '==' (a single '=' is not an operator)", "!b" дає
  "line 2:1: expected '!=' (a single '!' is not an operator)".
- П'ять програм-помилок Task 2 (по одному правилу: bool у +, bool у
  порівнянні з i32, i32{a+b} де a+b має тип i64, присвоєння i64 в i32
  mut-змінну, константа 3000000000 в i32) перевірено вручну — кожна
  дає рядок з методички дослівно, включно з "line 1:7: constant

  type i32 with a value of type i64". Ті самі п'ять програм із
  виправленим рядком перевірено — компілюються й дають очікуваний
  результат через lli.
- sext видно в output.ll на кожному з п'яти місць (ініціалізатор,
  присвоєння, операнди +-*, операнди ==!=, значення exit) — перевірено
